# ”SCOPE” at SemEval-2026 Task 6: Unmasking Political Question Evasions

Evasion and ambiguity is common in the po-
litical debate. This paper introduces SCOPE,
a pipeline for evasion classification based on
the taxonomy introduced by (Thomas et al.,
2024a). Given a question and a answer, SCOPE
gives it an evasion label. SCOPE showed lim-
ited potential, with lower accuracy than what
was presented by (Thomas et al., 2024a). Fur-
ther, fine-tuning and experimentation could be
done in order to enhance the overall accuracy
of the system. There are also several ethical
consideration regarding the dataset that has to
be addressed. This includes the difficulty to
find a ground truth for the same question and
answer. A model of this kind risks being biased
and creating further polarization in the political
debate.
